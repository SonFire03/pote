# Portfolio d'Evan Lamaire

Site statique (HTML/CSS/JavaScript) pour présenter le portfolio d'un pâtissier.

## Fichiers

- `index.html` : structure complète des sections.
- `style.css` : thème premium pâtisserie en mode nuit, responsive et animé.
- `script.js` : interactions UI (menu mobile, machine à écrire, filtres galerie, reveals, carte interactive, retour haut).

## Personnalisation rapide

1. Remplacer les textes provisoires : années, établissements, expériences.
2. Remplacer les images placeholder `https://placehold.co/...` par des photos réelles.
3. Mettre à jour les liens de contact et réseaux sociaux.
4. Remplacer le bouton CV par un vrai fichier PDF (ex: `assets/cv-evan-lamaire.pdf`).
5. Remplacer l'image placeholder du QR code.

## Lancer en local

Ouvrir `index.html` directement dans un navigateur, ou utiliser un serveur local simple.

## Déploiement GitHub Pages

1. Pousser les fichiers sur un dépôt GitHub.
2. Aller dans `Settings > Pages`.
3. Source : branche `main` (ou `master`) et dossier `/root`.
4. Enregistrer, puis attendre la publication.

## Notes

- Le formulaire de contact est visuel (front-end uniquement).
- Le code est prêt pour une adaptation progressive vers un back-end si nécessaire.
